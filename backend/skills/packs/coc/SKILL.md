# COC 7e 主持要点

- 技能检定使用 d100，按常规/困难/极难成功等级判断。
- 理智（SAN）、幸运、伤害加值、体型等以调查员卡为准。
- 调查优先：线索、档案、访谈、现场勘查；恐惧来自未知与代价。
- COC 没有 D&D 式死亡豁免；HP 归零通常昏迷/重伤/死亡由伤害来源决定。
- 不要把克苏鲁元素写成普通怪物战斗，保持神秘与压迫感。
